About

Hello! My name is Kayden Ireland, I’m a software developer from Pittsburgh, Pennsylvania.

I primarily work in Java and Rust as my primary software interests revolve around desktop apps, APIs, and language development. Recently I have been getting involved in game development and the use of C# on occasion. I am fascinated by how different languages work, so I enjoy branching out and using different languages for small things.

I have also enjoyed the process on working on my own programming language using Rust, which can be seen along with some of my other projects here.

Some of my hobbies involve sports, astronomy, geography, geo sciences, video games, and more. I love trying to incorporate these into projects when possible.
